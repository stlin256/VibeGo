# VibeGo brand assets

This directory contains the source-of-truth brand assets for VibeGo. The assets are SVG-first so they stay sharp in a README, web UI, PWA icon, or presentation.

| Asset | Intended use |
| --- | --- |
| `vibego-mark.svg` | Standalone app mark, empty states, product UI |
| `vibego-favicon.svg` | Browser favicon and small square icon |
| `vibego-logo.svg` | Light backgrounds |
| `vibego-logo-dark.svg` | Dark backgrounds |
| `vibego-banner.svg` | Repository/readme hero banner, 1600 × 520 |
| `vibego-og.svg` | Social preview card, 1200 × 630 |
| `tokens.css` | CSS custom properties for product UI |

The complete visual rationale, color rules, typography, and copy guidance live in [`docs/brand-guidelines.md`](../docs/brand-guidelines.md).
